# MIIT Smart Enrollment System

A mobile application designed to simplify and digitize the student enrollment process at the Myanmar Institute of Information Technology (MIIT).

## Overview

The MIIT Smart Enrollment System helps students complete their enrollment process digitally while allowing administrators to manage applications efficiently.

## Features

- Student registration and information management
- Digital signature submission
- Online payment integration
- PDF payment voucher generation
- Application status tracking
- Admin dashboard and role-based access
- Email notifications
- English and Myanmar language support
- Student document and photo uploads

## Tech Stack

**Frontend**
- Flutter
- Dart

**Backend and Database**
- Firebase Authentication
- Cloud Firestore
- Supabase Storage

**Development Tools**

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Firebase project configuration
- Supabase project configuration

### Installation

1. Clone the repository:

```bash
git clone https://github.com/oreo-aeint/miit_smart_enrollment_system.git
```

2. Navigate to the project directory:

```bash
cd miit_smart_enrollment_system
```

3. Install dependencies:

```bash
flutter pub get
```

4. Configure Firebase and Supabase using your own credentials.

5. Run the application:

```bash
flutter run
```

## Security

Private credentials, API keys, and environment-specific configuration files should not be committed to this repository.
